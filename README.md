# Смета за 5 минут

Веб-приложение для быстрого составления сметы или коммерческого предложения и сохранения результата в PDF.

Для кого:
- предприниматели — подготовить коммерческое предложение клиенту;
- офисные сотрудники — составить смету закупки или расчёт расходов для руководителя.

## Файлы приложения

Планируемые файлы:
- `index.html` — структура страницы: поля, кнопки и смета;
- `styles.css` — оформление и удобное отображение на компьютере и телефоне;
- `script.js` — расчёт сумм и логика действий пользователя, включая сохранение в PDF.

Сейчас созданы только `README.md` и `AGENTS.md`. Файлы приложения будут добавляться по отдельным запросам.

## Как открыть

Когда будет создан `index.html`, откройте его двойным щелчком. Приложение будет работать в браузере без установки зависимостей.

## Как проверить

Когда будет реализован расчёт, добавьте две позиции:
- 2 штуки по 15 000 ₸ — сумма 30 000 ₸;
- 1 штуку по 8 000 ₸ — сумма 8 000 ₸.

Ожидаемый итог: **38 000 ₸**.
